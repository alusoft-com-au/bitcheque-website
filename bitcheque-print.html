Bitcheque Print

Print more cheques of your book, offline

Use a clean computer with the internet switched off. This page works without any network: everything it needs is inside this one file. Your seed never leaves this computer and is never saved.

1Your seed

Type the 24 words of the book's seed, in order, separated by spaces.

Lookup code of this book:

It must match the code printed on your existing sheets. If it does not, a word is wrong.

2Which cheques

A book has cheques 1 to 255. Start after the highest cheque you already have. The explorer shows your last cheque used: a cheque number at or below it can never be used again.

3Save and print

Each part is saved as a file. Open it, print it, then delete it and empty the trash. Print part A and part B as separate print runs, on two USB printers if you can, and keep the two parts in different places.

4Then

  1. Delete the two part files, empty the trash, close this page and switch the computer and printers off.
  2. Take the registration file to any online computer and open bitcheque.org/onboard.html#register. A minute or two of computing per 16 cheques registers them. Your account number stays the same.
  3. Wait for the next block before you write any of the new cheques.
Reprinting a lost book? Print only cheque numbers above your last cheque used, never one the lost copy may already have been written on, and destroy the old copy if it turns up.
